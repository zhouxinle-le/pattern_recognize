# SVM 水面分割

本项目对航拍图 `00000341.jpg` 进行逐像素水面分割。每个像素使用 7 个特征，包括 3 个 Lab 颜色特征、2 个邻域纹理特征和 2 个位置特征。程序对比线性 SVM 的原始解、线性对偶解和 RBF 核对偶解。掩膜中白色表示水面，黑色表示其他区域。

## 运行

依赖 NumPy、SciPy、quadprog、OpenCV 和 Matplotlib。在项目目录运行 `python svm.py`，即可在一个窗口查看原图和三种方法清理前后的掩膜。默认读取 `data/` 中的标注，点选和框选分别使用 `extract_dot.py` 和 `extract_box.py`。

## 输出图像

[对比图](results/comparison.png)左侧是原图，右侧三列分别对应三种方法，上排为原始预测，下排为清理后的掩膜。清理保留最大的白色连通区域，并填补不超过 24 像素的封闭黑洞。

六张掩膜单独保存在 `results/`。原始掩膜为 `svm_qp.png`、`svm_dual.png`、`svm_rbf.png`，清理后的掩膜带 `_clean` 后缀。

## 实验比较

运行 `python svm.py --no-gui` 会在终端打印并更新[实验比较报告](results/experiment.md)。报告记录三种方法的训练与整图预测耗时、支持向量数量、清理前后的准确率和水面 IoU，以及掩膜之间的整图像素差异。两种线性解还比较了目标值、权重和偏置。

评估使用 [dot_20261106_215524.npz](data/dot_20261106_215524.npz) 中的 107 个手工标注点。按默认训练标注，排除 19 个与训练标注的 11×11 特征邻域重叠的点后，剩下 88 个留出点，水面和非水面各 44 个。
